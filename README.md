# Gestor de tareas TaskPilotIA

Aplicación web de gestión de tareas desarrollada con Django y MariaDB como proyecto académico de máster.

## Características

- Gestión de tareas
- Estados y prioridades
- Filtros de búsqueda
- Dashboard de productividad
- Histórico de cambios
- Sistema de notas
- Integración futura con IA

## Tecnologías utilizadas

- Python
- Django
- MariaDB
- HTML/CSS
- JavaScript
- Git/GitHub

## Instalación

### Clonar repositorio

git clone https://github.com/Ootoito/gestor-tareas-ia-master.git

### Crear entorno virtual

python -m venv .venv

### Activar entorno virtual

Windows:

.venv\Scripts\activate

### Instalar dependencias

pip install -r requirements.txt

### Configurar variables de entorno

Crear archivo .env usando .env.example

### Ejecutar migraciones

python manage.py migrate

### Lanzar servidor

python manage.py runserver
